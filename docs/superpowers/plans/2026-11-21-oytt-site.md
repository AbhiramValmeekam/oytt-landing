# OYTT Website Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Deliver the OYTT static website with a tested product demo and Firebase setup; defer legal copy per user steering.

**Architecture:** Astro static routes and shared layout/components; native CSS for the brand. Pure timestamp-based console state plus a small DOM controller. Build-time assets and SEO; no runtime services.

**Tech Stack:** Astro, JavaScript, self-hosted Fontsource fonts, Playwright, axe-core, Lighthouse.

**Spec:** docs/superpowers/specs/2026-11-21-oytt-design.md

## Global Constraints

- No gradients, blur, shadows, analytics, cookies or backend.
- Accent #FF5500, black pills, 22px slabs, 1px hairlines.
- All seven routes; four legal holding pages, as explicitly requested.
- Age decision recorded as 16+ with country-specific consent requirements, pending app implementation.
- Official unmodified Google Play badge; HTTPS canonical Firebase origin.

## Review Focus

1. Switching tasks must preserve elapsed time and only run one timer.
2. Reset/log must stop the selected timer without losing another task's time.
3. Theme must follow system unless overridden and tolerate blocked storage.
4. 360px layouts and enlarged text must not overflow.
5. Legal holding pages must not imply Play policy readiness.
